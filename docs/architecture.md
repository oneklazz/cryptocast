# Архитектура проекта

### Общая структура

- **app/main.py** - FastAPI сервер, эндпоинт `/predict`
- **core/forecast.py** - переиспользуемая функция прогноза
- **dataset/** - CSV-файлы с данными
- **redis** - кешэирование прогнозов
- **Docker** - контейнеризация
- **Makefile** - автоматизация команд
---
## Компоненты

### Core (ядро)
**Отвечает за прогноз, не зависит от FastAPI, Redis или других внешних сервисов**

### API (приложение)
**Вызывает core, управляет HTTP-запросами, добавляет кэширование через Redis**
