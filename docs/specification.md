# Спецификация проекта cryptocast

## Назначение

Сервис принимает название криптовалюты и горизонт прогноза в днях
и возвращает предсказанные цены закрытия на основе исторических данных.

## Пользователи

- **Аналитик** — отправляет запросы к API и получает прогнозы
- **Разработчик** — запускает, тестирует и развивает проект

## Сценарии использования

### UC-1: Получить прогноз цены

**Актор:** Аналитик

**Входные данные:**
- `coin` — название монеты (XRP, Ethereum, Dogecoin, Litecoin, Solana)
- `days` — количество дней прогноза (целое число > 0)

**Результат:** список дат и соответствующих прогнозируемых цен

**Ошибки:**
- Монета не найдена — файл данных отсутствует → ошибка сервера
- `days <= 0` — некорректный горизонт → ValueError

### UC-2: Запустить тесты

**Актор:** Разработчик

**Действие:** `make test`

**Результат:** все тесты проходят

### UC-3: Собрать и опубликовать пакет

**Актор:** Разработчик

**Действие:** `make build-lib` → `make publish-lib`

**Результат:** пакет cryptocast-core доступен на TestPyPI

## Ограничения

- Прогноз строится только по историческим ценам закрытия (Close)
- Данные должны содержать колонки Date и Close
- Минимальный горизонт прогноза — 1 день
- Поддерживается 5 монет (определяется наличием CSV-файла)
