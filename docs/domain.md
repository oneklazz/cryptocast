# Предметная область

## Основные сущности

**CoinDataset** — исторические данные о цене монеты.
Хранятся в CSV-файлах в папке `dataset/`.
Поля: Date, Open, High, Low, Close, Volume, Marketcap.

**ForecastRequest** — запрос на прогноз.
Поля: `coin` (название монеты), `days` (горизонт прогноза).

**ForecastResult** — результат прогноза.
Поля: `dates` (список дат), `values` (список прогнозируемых цен).

## Бизнес-правила

- `days` должно быть строго больше нуля
- Название монеты должно соответствовать существующему CSV-файлу
- Прогноз строится на основе всей доступной истории цен
- Результаты кэшируются в Redis

## Словарь терминов

| Термин | Описание |
|--------|----------|
| `coin` | Криптовалюта (XRP, Ethereum и др.) |
| `days` | Горизонт прогноза в днях |
| `forecast` | Результат предсказания цены |
| `Close` | Цена закрытия торгового периода |
| `Prophet` | Библиотека временных рядов от Meta |
| `cache` | Кэш результатов в Redis |
